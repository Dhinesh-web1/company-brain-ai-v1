COMPANY BRAIN AI — Version 1
=============================

What it does
- Add sales/expense records
- Calculates total revenue, expenses, estimated profit/loss, and units sold
- Generates basic rule-based business insights
- Saves records in the current browser's local storage
- Copies a summary and exports records to CSV

Important limitations
- This is an early demo, not a production enterprise product.
- It does not connect to a generative AI model yet; current insights are rule-based.
- Data is stored in the browser on the device and may be lost if browser data is cleared.
- Do not enter confidential, personal, or real customer/company data.
- Profit is an estimate based on the expenses entered; it is not audited accounting.

Run it on Android
Option A — easiest if the file can be opened:
1. Extract the ZIP.
2. Open index.html in a browser. Some Android file managers/browsers may restrict local-file behavior.
3. If it does not work, use Option B.

Option B — publish a demo with GitHub Pages (free, requires a GitHub account):
1. Open https://github.com in your browser and create/sign in to an account.
2. Create a new repository named company-brain-ai-v1.
3. Choose Public for a free GitHub Pages demo, and do not upload any private data.
4. Add/upload index.html from this folder to the repository root.
5. In the repository, open Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
7. Wait for publishing, then open the URL shown in the Pages section. It usually looks like https://YOUR-USERNAME.github.io/company-brain-ai-v1/
8. Open that URL in Chrome on Android. Use Chrome menu → Add to Home screen if you want a shortcut.

If you cannot upload from mobile:
- In GitHub's repository, use Add file → Create new file, name it index.html, and paste the contents of index.html from this package. For a large file, uploading the file from a file picker is easier.
- Tell ChatGPT which screen you see and I can guide you from there.

Privacy
Do not put API keys, passwords, private data, or confidential company data into the public repository.
